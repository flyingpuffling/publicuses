MM TRADE VAULT — ANDROID INSTALL

For an actual home-screen app (recommended):
1. Unzip this package.
2. Upload the CONTENTS of the folder to an HTTPS static site (for example Netlify Drop or GitHub Pages).
3. Open the public HTTPS URL in Chrome on Android.
4. Tap Chrome's three-dot menu, then Add to Home screen or Install app.
5. Once opened online once, the PWA is cached for offline use.

For use without a website:
Open Merge_Mansion_Trade_Vault_Android.html from the Downloads folder in a compatible browser. The app works without the internet, but Android Chrome may not allow adding file:// pages to the home screen.

Data edits are kept in the browser's local storage for the URL/origin used. Data can be lost if browser storage is cleared, the URL/domain changes, or a local file is moved.
Use Menu > Export backup (.json) to save a copy, then Menu > Import backup to restore it.
